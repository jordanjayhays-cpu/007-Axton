# Niah — Target Customer

## Primary: Event Organizers

They pay for Niah because:
- Better attendee experience = more sponsors / tickets
- Differentiation from other events
- Data on who networking with whom

## Secondary: B2B Professionals

They use Niah because:
- Pre-event curation — know who's attending, who's relevant
- No more random networking
- Save time, make better connections

## Ideal Customer Profile

- Hosts 50-500 person events in Madrid
- B2B / professional focus
- Tech, finance, healthcare, professional services
- Already has LinkedIn Premium / paid networking tools

## Key Buying Triggers

- Event attendees complaining about "empty networking"
- Low return-visitor rates
- Negative feedback on event apps
- Competition from better-organized events
